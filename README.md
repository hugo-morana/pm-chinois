# pm-chinois

Palais mental 3D du chinois mandarin (汉语宫) : réplique du palais italien (9 581 niches, mêmes phrases d'exemple françaises), traductions en chinois natif avec pinyin.

- `index.html` : le palais (page autonome, données intégrées)
- `audio/` : sons (mots et phrases)
- `sources/` : contenus par salle (`zh_<salle>.txt`, une ligne par niche) et données générées
- `outils/` : scripts de construction (`build_zh.py`, `make_site.py`)
